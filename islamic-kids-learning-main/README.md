# تعلّم وابتسم 🌙⭐

تطبيق Flutter تعليمي للأطفال بطابع إسلامي.

## الميزات
- الحروف العربية والإنجليزية والأرقام مع النطق.
- ألعاب تعليمية: صائد الحروف، بطل الأرقام، والتحدي السريع.
- قسم إسلامي مبسط للأطفال.
- نقاط ونجوم ومستويات وشارات.
- متجر مكافآت.
- حفظ التقدم محلياً.
- واجهة عربية RTL وألوان عالية التباين.

## بناء APK
يوجد GitHub Actions في `.github/workflows/build-apk.yml`، ويبدأ البناء تلقائياً عند الدفع إلى `main`.

بعد نجاح البناء افتح **Actions** ثم نتيجة **بناء APK** ثم **Artifacts** وحمّل `islamic-kids-learning-apk`.
