# تعديلات نسخة رياض الأطفال

## التعديلات
- تغيير أيقونة قسم الحروف العربية من رمز إنكليزي إلى `أب`.
- إضافة صديق تعليمي باسم «نور» برسمة طفلة محتشمة، مع واجهة محادثة للأطفال.
- المساعد يستخدم إجابات محلية آمنة عند عدم وجود خادم ذكاء اصطناعي، ويمكن ربطه بخادم API متوافق مع OpenAI عبر `AI_ENDPOINT` و`AI_API_KEY` و`AI_MODEL`.
- تحسين الصوت العربي: التطبيق يحاول اختيار `ar-SY` أولاً، ثم `ar-LB` أو `ar-JO` أو `ar-SA` حسب الأصوات المثبتة على الهاتف، مع رفع مستوى الصوت وإبطاء النطق.
- قسم آداب الإسلام أصبح على شكل بطاقات نصيحة متتابعة: نصيحة 1 ثم التالية ثم التالية، مع زر سماع النص.
- خصوصاً آداب الصلاة: عدة نصائح مستقلة يمكن قلبها واحدة تلو الأخرى.
- قسم الحيوانات أصبح بصور رسومية كبيرة بدلاً من الرموز الصغيرة.
- زر الحيوان يشغل **صوت الحيوان فقط** ولا يشغل كلاماً بشرياً.
- أصوات الحيوانات تستخدم ملفات صوت من Wikimedia Commons عبر الإنترنت؛ لذلك تحتاج اللعبة إلى اتصال إنترنت عند تشغيل الصوت.
- التلوين أصبح بالقلم والسحب بالإصبع مع ألوان وحجم قلم ومسح وتراجع وتبديل صفحات تلوين.

## الذكاء الاصطناعي
لربط نموذج فعلي لا تضع مفتاح API ثابتاً داخل التطبيق المنشور. الأفضل استخدام خادم وسيط آمن.

مثال عند البناء:

```text
flutter build apk --release --dart-define=AI_ENDPOINT=https://your-server.example/v1/chat/completions --dart-define=AI_API_KEY=YOUR_KEY --dart-define=AI_MODEL=gpt-4o-mini
```

إذا لم تضف مفتاحاً أو خادماً، يعمل «نور» بإجابات محلية آمنة بدلاً من إظهار خطأ.

## الصوت العربي
جودة الصوت تعتمد على محرك TTS والأصوات العربية المثبتة على هاتف Android. التطبيق يفضّل `ar-SY` إن كان متوفراً. إذا لم يكن موجوداً، يختار صوتاً عربياً متاحاً.

- اعتماد الاسم الرسمي الجديد للتطبيق: «طفلي المسلم».
- إضافة أيقونة خارجية للأطفال الكرتونيين المحتشمين، مع تجهيزها كأيقونة Android عبر flutter_launcher_icons.
- إضافة صورة الهوية نفسها إلى شاشة البداية وشاشة اختيار الطفل وواجهة التطبيق.
- تحديث GitHub Actions ليستخدم الاسم «طفلي المسلم» ويولّد أيقونة التطبيق تلقائياً قبل بناء APK.
