# طفلي المسلم — النسخة النهائية قبل بناء APK

تم تجهيز المشروع ليكون تطبيق Android تعليمي للأطفال بطابع إسلامي، مع التركيز على البساطة والألوان الواضحة.

## المزايا الموجودة
- واجهة عربية RTL باسم **طفلي المسلم**.
- شخصية **نور** بظهور بصري مستوحى من صورة التطبيق، مع صوت TTS عربي.
- محاولة استخدام `ar-SY` أولاً، ثم أصوات عربية بديلة إذا لم يدعم الهاتف الصوت السوري.
- ملفات أطفال متعددة وحفظ النقاط محلياً.
- الحروف العربية مع النطق.
- الحروف الإنجليزية مع النطق.
- الأرقام العربية حتى 100.
- رياضيات بثلاثة مستويات: سهل، متوسط، متقدم.
- جمع وطرح وضرب وقسمة صحيحة، مع مسائل كلامية.
- الرسم الحر والتلوين ومسح/تراجع وتغيير حجم القلم.
- عالم الحيوانات مع رسومات تعليمية وأزرار أصوات حقيقية عبر الإنترنت للقطة والكلب والبقرة والأسد.
- 12 محوراً في آداب الإسلام والأخلاق.
- اختبار إسلامي تفاعلي مع نقاط.
- لعبة المطابقة.
- صفحة رحلة تعليمية تجمع مسار التعلم.
- نظام نجوم ونقاط ومكافآت.
- مساعد نور الذكي مع وضع محلي آمن، ودعم خادم AI اختياري من إعدادات الأهل.
- شعار التطبيق والهوية البصرية محدثان.
- إعداد Android في GitHub Actions جاهز لبناء APK.

## ملاحظات مهمة قبل الإصدار
1. الصوت السوري يعتمد على محرك TTS والأصوات المثبتة على جهاز Android؛ التطبيق يحاول `ar-SY` لكنه لا يستطيع إجبار الهاتف على توفير صوت سوري غير مثبت.
2. أصوات الحيوانات الحالية تأتي من روابط Wikimedia، لذلك تحتاج اتصال إنترنت. تم إضافة إذن الإنترنت في Workflow الخاص ببناء APK.
3. لا يوجد مفتاح API ثابت داخل التطبيق؛ المساعد يستخدم إجابات محلية إذا لم يتم إعداد خادم آمن.
4. يجب تنفيذ بناء APK واختبار التطبيق على هاتف Android فعلي قبل اعتبار الإصدار Production.
