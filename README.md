# طفلي المسلم 🌙⭐

تطبيق Flutter تعليمي للأطفال بطابع إسلامي.

## التعديلات الحالية
- الاسم الرسمي للتطبيق: **طفلي المسلم**.
- أيقونة خارجية لطفل وطفلة كرتونيين محتشمين.
- صورة الهوية داخل التطبيق.
- الحروف والأرقام والألعاب التعليمية.
- صديق الطفل «نور» وواجهة أسئلة مناسبة للأطفال.
- تحسين اختيار الصوت العربي مع تفضيل `ar-SY` عند توفره على الهاتف.
- آداب الإسلام على شكل نصائح متتابعة يمكن الانتقال بينها واحدة تلو الأخرى.
- الحيوانات بصور كبيرة وأصوات حيوانات فقط.
- التلوين بالقلم والسحب بالإصبع مع الألوان وحجم القلم والتراجع والمسح.

## بناء APK
يوجد GitHub Actions في `.github/workflows/build-apk.yml` لبناء APK عند الدفع إلى `main`.

تم إدراج النسخة المعدلة الكاملة في `lib/main.dart` وتجهيزها للبناء.
