# كيف تحصل على APK باستخدام GitHub (بدون تثبيت أي شيء على جهازك)

## الخطوة 1: أنشئ مستودع (Repository) على GitHub
1. افتح https://github.com وسجّل دخول (أو أنشئ حساباً مجانياً).
2. اضغط على زر "+" أعلى الصفحة ثم "New repository".
3. اختر اسماً مثل: `islamic-kids-learning` واضغط "Create repository".

## الخطوة 2: ارفع ملفات المشروع
### الطريقة السهلة (بدون سطر أوامر):
1. افتح صفحة المستودع الذي أنشأته.
2. اضغط "Add file" ثم "Upload files".
3. اسحب مجلد `islamic_kids_learning` بالكامل (بعد فك الضغط) وأفلته هناك.
   **مهم:** تأكد أن مجلد `.github/workflows/build-apk.yml` مرفوع أيضاً (قد يكون مخفياً، فعّل إظهار الملفات المخفية عند الرفع أو استخدم سطر الأوامر بالأسفل).
4. اضغط "Commit changes".

### الطريقة عبر سطر الأوامر (أدق وتضمن رفع كل الملفات المخفية):
```bash
cd islamic_kids_learning
git init
git add .
git commit -m "أول رفعة للمشروع"
git branch -M main
git remote add origin https://github.com/USERNAME/islamic-kids-learning.git
git push -u origin main
```
(استبدل USERNAME باسم حسابك على GitHub)

## الخطوة 3: انتظر بناء APK تلقائياً
1. بمجرد الرفع، اذهب لتبويب **Actions** في صفحة المستودع.
2. ستجد عملية باسم "بناء APK" تعمل تلقائياً (تأخذ حوالي 5-10 دقائق).
3. عند اكتمالها بعلامة ✅ خضراء، افتحها.
4. في أسفل الصفحة، ستجد قسم **Artifacts** يحتوي ملف باسم:
   `islamic-kids-learning-apk`
5. اضغط عليه لتنزيله (سيكون ملف zip يحتوي app-release.apk بداخله).

## الخطوة 4: التثبيت على جهاز أندرويد
1. انقل ملف `app-release.apk` إلى هاتف أندرويد.
2. فعّل خيار "تثبيت من مصادر غير معروفة" إن طُلب ذلك.
3. اضغط على الملف للتثبيت.

## ملاحظة
كل مرة تعدّل فيها الكود وترفعه (push) إلى GitHub، سيُبنى APK جديد تلقائياً — لا تحتاج تكرار أي خطوة يدوياً.
