# تطبيق تعلّم وابتسم 🌙⭐
تطبيق تعليمي للأطفال (Flutter) لتعليم الحروف العربية والإنجليزية والأرقام
مع نطق صوتي، شخصية كرتونية محتشمة، رسائل تشجيعية إسلامية، ونظام مكافآت.

## طريقة التشغيل
1. تأكد من تثبيت Flutter SDK (نسخة 3.0 فأعلى):
   https://docs.flutter.dev/get-started/install
2. من داخل مجلد المشروع نفّذ:
   ```
   flutter pub get
   flutter run
   ```
   (وصّل جهاز أندرويد حقيقي أو شغّل محاكي Android Emulator أولاً)

3. لبناء ملف APK جاهز للتثبيت:
   ```
   flutter build apk --release
   ```
   ستجد الملف الناتج في:
   `build/app/outputs/flutter-apk/app-release.apk`

## هيكل المشروع
```
lib/
 ├─ main.dart                     # نقطة التشغيل
 ├─ models/child_profile.dart     # نموذج بيانات الطفل
 ├─ services/
 │   ├─ profile_service.dart      # حفظ/تحميل الملف الشخصي محلياً
 │   └─ tts_service.dart          # خدمة النطق الصوتي
 ├─ data/content_data.dart        # الحروف والأرقام والرسائل التشجيعية
 ├─ widgets/mascot_widget.dart    # الشخصية الكرتونية (رسم أصلي)
 └─ screens/
     ├─ profile_setup_screen.dart # تسجيل الملف الشخصي
     ├─ home_screen.dart          # القائمة الرئيسية
     ├─ learning_screen.dart      # تعلم الحروف/الأرقام + نطق صوتي
     ├─ reward_screen.dart        # لعبة المكافأة + رسائل تشجيعية
     └─ progress_screen.dart      # سجل المتابعة والتقدم
```

## أفكار للتطوير لاحقاً
- استبدال الشخصية المرسومة برمجياً بصور SVG/PNG احترافية من مصمم رسوم.
- إضافة أصوات نطق مسجّلة بدلاً من محرك TTS النظام لجودة صوت أعلى للأطفال.
- ربط سجل المتابعة بحساب سحابي (Firebase) لدعم عدة أطفال/أجهزة.
- إضافة تمارين "طابق الحرف بالصورة" أو "أكمل الرقم الناقص".
- دعم عدة ملفات أطفال (إخوة) بدلاً من ملف واحد فقط.
